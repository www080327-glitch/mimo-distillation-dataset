# Verify and recover a recorded v1.9.0 step

Run this from the repository root with Python 3.10 or later. Use the local
v1.9.0 release tar, its standalone `MANIFEST.json`, the official
`SHA256SUMS`, and a directory containing the already downloaded bases. The
output directory must exist and must not contain `step8.zip` or `step8.json`.

The example uses only local files. It checks the release pins, obtains
verified base arguments, recovers the four files recorded after step 8,
and checks the ZIP against the pinned source. In this episode, step 8
contains the updated `abc-policy.js` and the newly released
`release-01.md`. No project code runs.

Save this block as `recover_step8.py`:

```python
import json
from pathlib import Path
import subprocess
import sys

archive, manifest, checksums, bases, destination = map(Path, sys.argv[1:])
episode = "64bdb4b0d2d1682d3ea5"


def run(script, *args):
    return subprocess.check_output(
        [sys.executable, script, *map(str, args)], text=True
    )


release = json.loads(run("check_abc_release.py", archive, manifest, checksums))
plan = json.loads(run("download_abc_bases.py", manifest, bases))
base_args = plan["replay_args"]
zip_file, receipt = destination / "step8.zip", destination / "step8.json"
print(run("restore_replay_step.py", archive, "--episode", episode,
          "--step", 8, "--output", zip_file, "--receipt", receipt, *base_args),
      end="")
proof = json.loads(run("verify_step_receipt.py", zip_file, receipt,
                       "--source-archive", archive,
                       "--source-sha256", release["archive_sha256"], *base_args))
assert proof["step"] == 8 and proof["files_verified"] == 4
print(json.dumps(proof, indent=2))
```

```sh
python3 recover_step8.py mimo-nextgen-abc-v1.9.0.tar.gz MANIFEST.json SHA256SUMS "base archives" output
```

The base planner exits nonzero if a base is missing or has a wrong SHA-256.
In that case the script stops before writing the step ZIP. The argument
array preserves paths with spaces and is never interpreted as a shell
command.
